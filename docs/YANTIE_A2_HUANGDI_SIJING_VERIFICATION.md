# 盐铁会议 A2《黄帝四经》版本、来源与短摘核验

文档性质：《黄帝四经》/《黄帝书》候选短摘与版权边界；本轮不修改 UI、API、Schema、evidence pack 或运行态数据。

## 1. 核验结论

本轮只把《黄帝四经》相关材料推进到“可候选、待入包”的状态，暂不进入 evidence pack。

当前可确认的边界：

1. 可采用谨慎命名：马王堆《老子》乙本卷前古佚书，通称《黄帝四经》/《黄帝书》/黄老帛书。
2. 可把它作为汉初黄老思想的关键透镜来源，但不能作为盐铁会议事实证据。
3. 可使用极短原文片段作为候选短摘，但最终入包前必须确认底本、版本、版权和逐条卷篇定位。
4. 不复制现代整理本、校注本、译本、论文或专著的长段内容。
5. 不支撑 `original_fact` Claim，只能支撑 `philosophy_lens`、`curatorial_inference` 或退朝后思想史导览。
