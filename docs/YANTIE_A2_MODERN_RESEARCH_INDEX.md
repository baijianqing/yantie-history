# 盐铁会议 A2 现代研究书目卡与版权边界

状态：A2 现代研究索引文档
任务 ID：`YT-A2-MAT-004`
文档性质：退朝后延伸阅读与研究史定位；不作为首次主体验材料；不写入 `evidence_pack.json`。

## 1. 使用原则

现代研究只用于帮助用户理解研究史、问题意识和进一步阅读路径，不作为盐铁会议事实的直接证据。

本索引只交付：

- 书目元数据。
- 公开链接。
- 原创观点定位。
- 使用边界。
- 版权边界。
- 人工核验状态。

本索引不交付：

- 现代论文或专著全文。
- 长段摘录。
- 需要授权的章节内容。
- 以现代研究替代《盐铁论》《汉书》《史记》《资治通鉴》等史料的历史判断。

## 2. 进入边界

| 位置 | 是否允许 | 说明 |
|---|---|---|
| 首次主体验 | 不允许 | 避免用户在入朝前被现代解释框定 |
| 退朝后深度探索 | 允许 | 作为延伸阅读与研究史定位 |
| 史证抽屉 | 不允许 | 现代研究不是会议事实证据 |
| 思想透镜 | 谨慎允许 | 只能作为研究视角说明，不可冒充原典思想 |
| evidence pack | 暂不进入 | 需另开任务定义 `modern_research` 入包规则 |
| external_echo | 不混入 | 当代评论和现代学术研究必须分开 |

## 4. 后续入包条件

现代研究如需进入 `evidence_pack.json`，必须另开任务并满足以下条件：

1. 新增或复用 `modern_research` source 时，`delivery_policy` 应默认为 `metadata_only` 或 `link_only`。
2. 不得创建现代研究 EvidenceUnit 来支撑 `original_fact` Claim。
3. 只能支撑研究史、接受史、体验策展说明或延伸阅读。
4. 观点摘要必须是原创概括，不得复制论文摘要或出版社介绍。
5. 每条现代研究材料必须标明版权边界和人工核验状态。
6. 如果需要引用短摘，必须另行核验版权和许可，不在 `YT-A2-MAT-004` 范围内处理。
