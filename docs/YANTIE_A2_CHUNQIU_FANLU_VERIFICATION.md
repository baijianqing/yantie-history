# 盐铁会议 A2 《春秋繁露》版本性质与候选短摘核验

状态：A2 经学语境候选短摘核验文档  
任务 ID：`YT-A2-MAT-006B`  
文档性质：文本性质、版本风险、候选短摘和入包边界；本轮不修改 UI、API、Schema、evidence pack 或运行态数据。

## 1. 核验目标

`YT-A2-MAT-006A` 已核验《汉书》中的董仲舒、武帝文治和经学官学材料。本任务继续核验《春秋繁露》候选材料，用于补足经学语境中的德刑、天人、王道、正朔和春秋义法。

本任务的重点不是证明《春秋繁露》全部为董仲舒亲撰，而是给后续 `YT-A2-MAT-006C` 提供一组可谨慎使用的候选短摘，并明确这些材料只能作为思想史背景或哲学透镜。

## 2. 文本性质边界

1. 《春秋繁露》采用传世文本，传统上归于董仲舒，但作者归属、成书年代和篇章层次存在研究争议。
2. 本项目只把它称为“董仲舒相关思想传统”或“经学解释材料”，不直接称为盐铁会议事实来源。
3. 本项目不声称桑弘羊、贤良文学或霍光直接引用《春秋繁露》。
4. 候选短摘不支撑 `original_fact` Claim，不作为会议现场证据。
5. 后续如入 evidence pack，材料类型只能候选为 `philosophy_lens`、`classics_context` 或 `curatorial_inference`。
6. 所有短摘保持极短，不复制整篇、整段、现代校注、现代译文或论文长段内容。
