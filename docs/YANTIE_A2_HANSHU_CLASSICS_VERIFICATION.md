# 盐铁会议 A2 《汉书》经学语境候选短摘核验

状态：A2 经学语境候选短摘核验文档  
任务 ID：`YT-A2-MAT-006A`  
文档性质：候选短摘、来源定位和入包边界；本轮不修改 UI、API、Schema、evidence pack 或运行态数据。

## 1. 核验目标

`YT-A2-MAT-006` 已确认董仲舒、经学语境和武帝文治正当性是 A2 思想史第二优先级。本任务只核验《汉书》三处候选来源：

- 《汉书·董仲舒传》：董仲舒、春秋学、贤良对策、推明孔氏和学校之官。
- 《汉书·武帝纪》：武帝纪赞中的文治叙事、表章六经和兴太学。
- 《汉书·儒林传》：经学在汉初至武帝、昭帝时期的制度化过程。

这些材料可为退朝后的经学思想透镜提供依据，但不作为盐铁会议现场事实。

## 2. 使用边界

1. 本轮只登记候选短摘，不写入 evidence pack，不新增 Source、EvidenceUnit 或 Claim。
2. 候选短摘只作 `philosophy_lens`、`institutional_context` 或 `curatorial_inference` 的候选材料。
3. 不支撑 `original_fact` Claim，不作为盐铁会议现场事实。
4. 不声称桑弘羊、贤良文学或霍光直接引用董仲舒、《汉书·董仲舒传》或《汉书·儒林传》。
5. 不把“罢黜百家，独尊儒术”作为未经拆解的产品文案；如使用，必须回到《汉书》的可定位短摘。
6. 所有候选短摘必须保持极短，不复制整段古文、现代译文、校注或研究著作长段内容。
