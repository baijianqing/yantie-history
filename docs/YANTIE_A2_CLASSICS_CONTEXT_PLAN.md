# 盐铁会议 A2 董仲舒、经学语境与政治正当性材料补强计划

状态：A2 思想史材料计划文档  
任务 ID：`YT-A2-MAT-006`  
文档性质：候选来源、解释边界与后续任务契约；本轮不修改 UI、API、Schema、evidence pack 或运行态数据。

## 1. 为什么要补经学语境

A2 已经补入黄老与《黄帝四经》材料，避免把盐铁会议读成简单的儒法二分。但当前思想史层还有另一处缺口：武帝以后，经学逐步成为国家正当性语言，贤良文学、大夫一方和会议记录者都处在这一政治语境之后。

如果只补黄老而不补董仲舒、经学官学和武帝文治叙事，用户会误以为盐铁会议中的“儒家批判”只是民生伦理，而看不到更深的制度变化：经义开始进入国家治理，贤良文学被朝廷召问，政策争论也开始借助《春秋》、六经、德刑、天人和名分语言来表达。

本任务的目标不是把盐铁会议改写成董仲舒思想的直接延伸，而是建立一组退朝后的思想透镜，让用户理解：

- 为什么“贤良文学”不是普通读书人，而是经学政治兴起后的议政角色。
- 为什么武帝财政国家不仅需要钱，也需要新的政治正当性。
- 为什么盐铁争论会不断诉诸先王、六经、仁义、名分和德刑。
- 为什么“独尊儒术”不能被写成一个简单口号，而应放回武帝文治、官学制度和后世概括中谨慎处理。

## 2. 使用边界

1. 不把董仲舒或《春秋繁露》当作盐铁会议现场证据。
2. 不声称桑弘羊、贤良文学或霍光直接引用董仲舒、《春秋繁露》或《春秋公羊传》。
3. 不用“罢黜百家，独尊儒术”概括全部武帝政治；如使用，只作为后世通行概括，并回到《汉书·武帝纪》“罢黜百家，表章六经”和《汉书·董仲舒传》“推明孔氏，抑黜百家”等可定位文本。
4. 《春秋繁露》文本层次复杂，后续如入包，只能作为董仲舒相关思想传统或经学解释材料，必须标注版本来源和文本性质，不直接支撑会议事实 Claim。
5. 经学材料默认只进入退朝后思想透镜或深度探索；只有另行验收后，才可作为主线轻提示。
6. 本轮只做计划与契约，不进入 evidence pack，不新增 Claim，不修改 UI。

## 4. 候选思想透镜

### CLC-LENS-001：春秋入政

- 材料方向：《汉书·董仲舒传》《春秋公羊传》相关材料。
- 解释目标：说明《春秋》不只是历史记录，也能成为判断政治正当性和制度得失的解释框架。
- 对盐铁体验的作用：帮助用户理解贤良文学为什么会把财政制度问题推向治道、仁义和先王之法。
- 推荐标签：`classics_context`、`gongyang`、`political_legitimacy`、`philosophy_lens`
- 默认入口：退朝后思想透镜。
- 入包条件：必须核验短摘、卷篇和版本；不得声称会议人物直接引用。

### CLC-LENS-002：推明孔氏，抑黜百家

- 材料方向：《汉书·董仲舒传》贤良对策与董仲舒政治建议。
- 解释目标：把“经学正当性”作为武帝以后政治语言的一部分，而不是把它简化为单一意识形态胜利。
- 对盐铁体验的作用：解释为什么盐铁会议中的“贤良文学”能够被朝廷召问，并以经典语言批评政策。
- 推荐标签：`dong_zhongshu`、`six_classics`、`orthodoxy`、`philosophy_lens`
- 默认入口：退朝后思想透镜。
- 入包条件：只取极短短摘；必须注明这是思想史背景，不支撑盐铁会议事实 Claim。

### CLC-LENS-003：德刑次序

- 材料方向：《春秋繁露·基义》及董仲舒相关德刑材料。
- 解释目标：呈现“德教与刑罚”的先后和比例问题，说明经学语境不是不要制度，而是要求制度服从德义秩序。
- 对盐铁体验的作用：补足贤良文学批评的制度伦理维度，也让用户看到财政官营并非只在效率层面受审。
- 推荐标签：`virtue_punishment`、`classics_context`、`statecraft`、`philosophy_lens`
- 默认入口：退朝后思想透镜。
- 入包条件：必须完成《春秋繁露》版本和文本性质核验；不得引用长段现代译文。

### CLC-LENS-004：天人灾异与君责

- 材料方向：《春秋繁露·人副天数》《同类相动》等相关材料。
- 解释目标：说明汉代经学如何把自然、灾异、政治责任和君主修德联系起来。
- 对盐铁体验的作用：帮助用户理解为什么财政、饥馑、民怨和政治正当性会被放在同一套语言里讨论。
- 推荐标签：`heaven_human_response`、`disaster_politics`、`ruler_responsibility`、`philosophy_lens`
- 默认入口：退朝后思想透镜。
- 入包条件：只作思想透镜；必须区分古人灾异解释与现代因果判断。

### CLC-LENS-005：五经博士与官学

- 材料方向：《汉书·儒林传》《汉书·武帝纪》关于五经博士、弟子员、太学和经学入仕的材料。
- 解释目标：解释经学如何从经典阅读进入官僚制度，成为国家选人和议政的一部分。
- 对盐铁体验的作用：让用户理解“贤良文学”的制度位置，而不只是把他们看成道德批评者。
- 推荐标签：`official_classics`、`five_classics_doctors`、`institutional_context`、`curatorial_inference`
- 默认入口：退朝后深度探索；可候选为主线轻提示。
- 入包条件：可作制度背景 EvidenceUnit，但必须标明不是盐铁会议现场证据。

### CLC-LENS-006：武帝文治与财政国家

- 材料方向：《汉书·武帝纪》赞、《汉书·食货志》《史记·平准书》已入包财政背景。
- 解释目标：把武帝时期的文治正当性和财政动员放在同一历史背景中理解。
- 对盐铁体验的作用：说明盐铁会议不是单纯“是否赚钱”的争论，而是武帝国家能力、文治叙事和昭帝政治调整之间的余波。
- 推荐标签：`wudi_context`、`fiscal_state`、`political_legitimacy`、`curatorial_inference`
- 默认入口：退朝后思想透镜和材料导览。
- 入包条件：如进入 evidence pack，应优先作为策展解释或制度背景，不支撑会议事实 Claim。
