## 3. 版权与摘录规则

- 古籍原文通常处于公有领域，但不同平台的整理、标点、校勘、注释和页面贡献可能有独立许可；交付包必须保留来源链接和采集日期。
- 现代白话译文、注释本、论文、专著和数据库内容不得全文交付，除非用户明确提供授权证明。
- 现代研究只能记录：书目信息、作者、出版信息、观点摘要、可公开链接、是否已人工核验。
- 交付包不包含原始 PDF、全书 Markdown、OCR 结果、Chroma 索引、向量、模型上下文缓存或完整 RAG 中间产物。
- 每条 EvidenceUnit 的原文摘录应满足“必要、短小、可定位”；无法确认许可的内容只保存定位和自写摘要。
- 知乎 REST/MCP 返回内容受平台条款和接口授权约束；作品可展示链接和摘要式当代回声，但不得把知乎内容复制为历史证据库。

## 4. Codex 采集职责

Codex 可以协助完成：

- 搜索公开古籍入口、官方/公共文库入口和用户本地已授权资料。
- 从允许来源抽取候选证据，并标注来源、篇章、页码或 URL、采集时间、摘录边界。
- 将大部头文本转成候选 EvidenceUnit、Claim 和 Relation，但必须保留“候选”状态，等待人工核验。
- 检查每条 Claim 是否区分原文事实、模型推断、争议观点和个人反思。
- 生成版权风险报告，标出不能交付、只能索引、只能链接或需要人工授权的材料。

Codex 不得完成：

- 自动把现代论文、译注、数据库文本全文放入交付包。
- 用模型记忆补齐无法定位的史料。
- 把知乎直答或搜索摘要当作古代史料证据。
- 为盐铁会议主题修改通用公共 Schema 或触发运行态知识库重切块。

## 5. 质量门

- 每条历史事实 Claim 至少绑定一条允许交付的 EvidenceUnit。
- 每条解释型 Claim 必须同时绑定原文证据和解释依据，且标注解释主体是作品策展、后世学者还是用户反思。
- 每条权力关系边必须标注证据强度：`explicit_source`、`contextual_inference` 或 `interpretive_hypothesis`。
- 无法定位到原文的内容只能进入“待核验材料”，不得进入可试玩主流程。
- 交付前生成 `source_manifest`，列出所有来源、许可判断、摘录数量、不可交付项和人工核验状态。
