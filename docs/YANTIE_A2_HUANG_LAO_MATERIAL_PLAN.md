# 盐铁会议 A2 汉初黄老与《黄帝四经》材料补强计划

状态：A2 思想史材料计划文档
任务 ID：`YT-A2-MAT-005`
文档性质：思想史透镜候选清单与进入边界；本轮不修改 UI、API、Schema、evidence pack 或运行态数据。

## 1. 为什么要补黄老

当前盐铁会议项目已经有较多儒家、法家、管子、韩非、商君书、礼记、淮南子等思想透镜，但汉初黄老语境仍然偏薄。

这会带来一个理解偏差：用户容易把盐铁会议看成简单的儒法对立，或者把桑弘羊一方理解成纯法家国家能力，把贤良文学一方理解成纯儒家民生批判。实际上，盐铁之议发生在汉武帝财政国家之后，也站在文景以来黄老政治传统的余波之中。黄老不是简单的“少做事”，而是把道、法、刑德、时势、名实和君主自约束放在同一个治理框架里。

因此，A2 思想史补强应优先建立“汉初黄老与《黄帝四经》”材料组，用来解释：

- 为什么“无为”并不等于无制度。
- 为什么“法”可以从“道”中获得正当性。
- 为什么国家能力需要节度、时机和名实校准。
- 为什么盐铁争论不能只用后来的儒法二分来读。

## 2. 命名与材料边界

《汉书·艺文志》著录“黄帝四经四篇”。马王堆三号汉墓出土的《老子》乙本卷前四篇古佚书，通常被称为《黄帝四经》《黄帝书》或“黄老帛书”。本项目采用谨慎表述：马王堆《老子》乙本卷前古佚书，通称《黄帝四经》/《黄帝书》/黄老帛书。

使用边界：

1. 不把《黄帝四经》当作盐铁会议现场证据。
2. 不声称桑弘羊、贤良文学或霍光直接引用了《黄帝四经》。
3. 不把“黄老”写成单一学派口号，应承认其兼有道、法、刑名、阴阳和战国政治术的复合性。
4. 不复制现代整理本、译本、论文或专著的长段内容。
5. 若未来进入 evidence pack，只能作为 `philosophy_lens` 或思想史背景材料，不得支撑 `original_fact` Claim。
6. 只有在版本、出处、版权和短摘都可核验后，才允许进入 evidence pack。

## 4. 候选思想透镜

### HLS-LENS-001：道生法度

- 材料方向：《黄帝四经·经法》相关段落。
- 解释目标：说明黄老并不排斥法，而是把法度放在道的秩序中理解。
- 对盐铁体验的作用：让用户理解“国家立法与制度经营”不必只归入法家强制，也可被放入黄老式秩序论。
- 推荐标签：`huang_lao`、`dao_fa`、`law_constraint`、`institutional_order`
- 入包条件：版本可核验；只摘短句；明确“思想透镜，不是会议事实”。

### HLS-LENS-002：刑德并用

- 材料方向：《黄帝四经》中刑、德、赏罚、教化关系材料。
- 解释目标：说明黄老治理不是单纯柔弱，而是关注刑德配合和治理节度。
- 对盐铁体验的作用：补足“宽民”与“制度执行”之间的中间层，避免把民生批判写成反制度。
- 推荐标签：`huang_lao`、`xing_de`、`reward_punishment`、`statecraft`
- 入包条件：必须区分原文事实、帛书解释和策展推断。

### HLS-LENS-003：因时制宜

- 材料方向：《黄帝四经》关于时、势、变、应的治理材料。
- 解释目标：呈现“顺时而治”的政治判断方式。
- 对盐铁体验的作用：解释盐铁政策为何在战时财政压力下有其现实理由，也为何在昭帝时期可能被重新审视。
- 推荐标签：`huang_lao`、`timely_governance`、`statecraft`、`policy_timing`
- 入包条件：不得把“因时制宜”写成用户可以改写历史结果的机制。

### HLS-LENS-004：名实与形名

- 材料方向：《黄帝四经》及相关黄老/刑名材料。
- 解释目标：说明政治判断需要校准名义、实际效果和制度职责。
- 对盐铁体验的作用：帮助用户追问“盐铁官营”名义上为国用，实际是否侵扰民生。
- 推荐标签：`huang_lao`、`xing_ming`、`name_reality`、`institutional_accountability`
- 入包条件：如涉及刑名学解释，必须标注为思想史推断，不冒充会议材料。

### HLS-LENS-005：无为与君主自约束

- 材料方向：《黄帝四经》《老子》《淮南子》相关无为、主术、君道材料。
- 解释目标：把“无为”解释为权力节制和制度顺势，而不是无政府或无政策。
- 对盐铁体验的作用：支撑霍光沉默、权力遮蔽和国家权力边界的解释。
- 推荐标签：`huang_lao`、`wuwei_governance`、`power_boundary`、`ruler_restraint`
- 入包条件：必须和《老子》、汉初史传材料分清来源层。

### HLS-LENS-006：黄老与财政国家的张力

- 材料方向：汉初黄老政治语境、武帝财政制度、昭帝盐铁会议之间的策展说明。
- 解释目标：说明盐铁会议不是单纯政策争执，而是汉初政治传统与武帝财政国家之间的回声。
- 对盐铁体验的作用：为退朝后思想透镜提供“为什么黄老能解释盐铁会议”的总论入口。
- 推荐标签：`huang_lao`、`fiscal_state`、`historical_context`、`curatorial_inference`
- 入包条件：只可作为策展解释或退朝后导览，不得写成古籍原文 Claim。
