## 1. 范围

本报告记录《盐铁会议：西汉朝堂复原》A1 静态交付包的验收结果。它验证当前 GitHub Pages 静态体验是否满足主体验可完成、证据链可审计、重型运行态数据不进入交付包、外部回声可降级和关键视口无明显遮挡。

本次允许范围：

- 一个 E2E/验收测试文件：`test/test_yantie_e2e.py`。
- 本验收报告：`docs/reports/YT-A1-E2E-001.md`。

本次未修改业务实现、公共 Schema、证据包内容、API 契约、运行态 `library/` 数据、前端页面或静态导出文件。

## 2. 已验证链路

### 2.1 静态交付包边界

验证对象：`docs/yantie/`

已确认：

- 静态页入口存在：`docs/yantie/index.html`。
- 静态证据包存在：`docs/yantie/data/evidence_pack.json`。
- 三段音频存在：`narrative.mp3`、`debate.mp3`、`reflection.mp3`。
- `index.html` 使用 `data-yantie-runtime="static"`。
- 静态运行时读取 `data/evidence_pack.json`，不依赖运行时 RAG、Chroma、向量库、OCR 中间产物或 `library/` 数据。
- 静态包体量低于 25 MB。

### 2.2 源文件与 Pages 导出一致性

已确认：

- `docs/yantie/data/evidence_pack.json` 与 `metaos/yantie/data/evidence_pack.json` 完全一致。
- `docs/yantie/index.html` 与 `render_yantie_static_html()` 输出完全一致。

这意味着当前 GitHub Pages 交付物没有落后于源渲染逻辑，也没有携带额外数据副本。

### 2.3 史证链闭合

已确认：

- 证据包版本为 `yantie_evidence_pack_v1`。
- 包 ID 为 `yantie_meeting_v1`。
- Sources、Actors、Events、EvidenceUnits、Claims、Relations 均达到 A1 最低数量要求。
- 每条 EvidenceUnit 均能回链 `source_id`，并包含 `canonical_location`、白话转述、版权说明和 `review_status=verified`。
- 历史 Claim 必须绑定 EvidenceUnit。
- 唯一无证据 Claim 为 `personal_reflection_prompt`，它属于退朝案牍中的用户反思提示，不作为历史判断。
- `external_references` 为空；外部回声不进入历史证据链。
- 证据包中不存在 `embedding`、`vector`、`raw_fulltext`、`rag_context` 等运行态字段。


`power-silence` 仍需人工复核，因为霍光沉默一幕的重点是留白、节奏和压迫感，不能只靠 DOM 断言判断。

### 2.5 外部回声降级

当前状态：

- 静态运行时返回 `external_echo_enabled=false`。
- “后世与当代讨论”入口显示为 disabled。
- UI 明确标注 `external_echo 暂不可用，不进入史证链`。
- 外部引用不会写入 Claim、EvidenceUnit 或退朝案牍。

结论：核心历史体验不依赖知乎接口；知乎 Adapter 未实现时，A1 静态体验可完整完成，并保持证据边界。
