# A1-E2E-001 Minimum Slice 发布门报告

状态：`blocked`

审查日期：`2026-06-26`

## 1. 范围

本报告记录 Core Alpha Minimum Slice 的首轮端到端冒烟验收。它验证本地 Core Alpha API、工作台读取路径和 Developer Diagnostics 权限边界是否可以协作，但不声称完整 Golden Cases 已执行。

本次允许范围：

- 一个 Core Alpha 端到端测试目录：`test/e2e/`。
- 本评测报告。
- `docs/ROADMAP.md` 中的发布门状态记录。

本次未修改业务规则、领域状态、检索策略、API 契约、fixture 期望或运行态数据。

## 2. 已验证链路

### 2.1 公开 API 与工作台读取路径

执行路径：

```text
create_app
-> POST /alpha/research-cases
-> POST /alpha/research-cases/{id}/source-resolutions
-> WorkbenchSnapshot 通过公开 API 读取 ResearchCase / SourceResolution / Scope / Judgment / Proposal / Feature
```

结论：

- ResearchCase 可通过公开 API 创建。
- 显式 required 来源未找到时形成 `SourceResolution.resolution_status=not_found`，不是 HTTP 404/503。
- 工作台快照能读取同一 ResearchCase。
- 无 JudgmentCard 时工作台显示“判断草稿”，不会伪造可采纳判断。
- 空 KnowledgeScope 不会伪造 required/excluded binding。

对应测试：

```powershell
.venv311\Scripts\python.exe -m pytest test\e2e\test_core_alpha_minimum_slice_gate.py
```

### 2.2 Developer Diagnostics 权限边界

执行路径：

```text
create_app(enable_developer_diagnostics=True)
-> GET /alpha/developer/projections/status
```

结论：

- Developer routes 可以被本地 Core Alpha API 挂载。
- 未携带 `X-Developer-Actor-Id` 时返回 401。
- 携带开发者身份后 projection status 可访问。
- Feature flag 能显示 developer diagnostics 已启用。

### 2.3 UI 浏览器冒烟检查

人工/浏览器检查：

- Streamlit 工作台：`http://localhost:8502`。
- Core Alpha API：`http://localhost:8000`。
- 桌面视口 `1366x900`：标题、创建 ResearchCase、知识范围、判断与证据、处置、知识目录均可见。
- 移动视口 `390x844`：标题换行正常，关键区域无明显重叠。
- API 启动后，工作台不再显示连接拒绝提示。
