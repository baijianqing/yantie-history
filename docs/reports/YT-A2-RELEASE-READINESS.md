# YT-A2-REL-001 盐铁会议 A2 发布适用性报告

状态：`preview_ready_with_conditions`

审查日期：`2026-07-14`

## 1. 范围

本报告只判断《盐铁会议：西汉朝堂复原》当前是否适合发布，以及适合发布到什么级别。

本轮不修改 UI、证据包、API、外部 adapter、验收脚本、公共 Schema、运行态数据或部署配置。

## 2. 当前项目状态

当前项目已经完成 A1 可试玩静态闭环，并完成 A2 第一轮材料补强与退朝后入口边界收口。

已经具备的能力：

- 主体验可以从开场压力、第一次取舍、入朝争论、关键证据、霍光沉默走到退朝案牍。
- GitHub Pages 静态交付物位于 `docs/yantie/`，不依赖运行时 RAG、向量库、OCR 中间产物或 `library/` 数据。
- evidence pack 已补入《资治通鉴》会议纪事、制度背景、文本性质、酒榷背景、制度人物、贤良文学身份、黄老透镜和经学语境透镜。
- 退朝后深度探索已覆盖材料导览、思想透镜分组、黄老分组、经学语境分组和外部回声边界提示。
- 当代回声仍标记为 `external_echo`，静态版默认禁用，不进入史证链、Claim、EvidenceUnit 或退朝案牍。

当前分支仍有未推送提交。发布到 GitHub Pages 前，必须先推送当前分支并触发或执行对应部署流程。

## 3. 已验证结果

本轮复核已确认：

- 盐铁相关 Python 测试通过：`83 passed`。
- 静态验收脚本在绑定工作区 Playwright 依赖后通过：`36/36 checks passed`。
- 静态验收仍建议人工复核：`desktop/power-silence`、`mobile/power-silence`、`reduced-motion/power-silence`。

注意：直接使用当前默认 Node 环境运行 `node scripts/check-yantie-acceptance.mjs` 会因为缺少 Playwright 失败。发布验收应使用工作区绑定的 Node 依赖，或后续单独补一项 Playwright 依赖可复现任务。

## 4. 发布判断

当前适合作为：

- GitHub Pages 静态预览版。
- A2 材料增强后的体验演示版。
- 对外小范围展示或参赛预览包。

当前不适合作为：

- 最终产品版。
- 生产级公开发布。
- 声称 A2 已完成的完整版本。

判断理由：

- 主体验和退朝后深度探索已经可完成，核心证据边界清楚。
- A2 材料补强已经进入 evidence pack 或退朝后导览，但尚未决定哪些材料应该作为主线轻提示出现。
- 外部回声 live adapter 仍不作为静态发布前置，当前只验证禁用和边界提示。
- `power-silence` 的情绪节奏仍需要人工观感复核，自动验收只能确认结构，不足以判断这一幕是否真正成立。
- 发布验收依赖 Playwright 环境，当前仓库还没有把 Node 验收依赖做成可复现的项目级安装说明或依赖清单。

## 5. 发布前条件

如果目标是发布 GitHub Pages 静态预览版，发布前至少完成：

1. 推送当前分支，确保 Pages 部署使用的是最新提交。
2. 使用绑定 Playwright 依赖运行静态验收脚本，确认 `36/36 checks passed`。
3. 人工复核三种 `power-silence` 场景，确认霍光沉默没有造成误解、卡顿感或移动端遮挡。
4. 确认外部回声入口仍为禁用态，并继续显示 `external_echo` 与“不进入史证链”的边界提示。
5. 打开部署后的 GitHub Pages URL，人工走完一次主体验和一次退朝后深度探索入口。

如果目标是最终公开发布，还需要继续推进后续任务，不建议现在直接发布为最终版。

## 6. 下一步建议

优先级最高的下一步不是继续塞材料，而是补齐发布门：

1. `YT-A2-E2E-001`：A2 静态发布门报告  
   记录部署 URL、静态验收输出、人工 `power-silence` 复核结论、移动端复核和剩余风险。

2. `YT-A2-REL-002`：Playwright 验收依赖可复现  
   选择一种方式固定验收运行方式：项目级依赖说明、脚本包装，或明确使用工作区绑定 Node 依赖。

3. `YT-A2-MAIN-001`：A2 材料进入主线轻提示决策  
   从《资治通鉴》会议纪事和制度背景材料中挑选极少数可进入主线的轻提示，其余继续留在退朝后深度探索。

4. `YT-A2-DOC-001`：发布说明与 README 收口  
   用普通用户能理解的语言说明当前版本是什么、能体验什么、哪些能力尚未开放。

## 7. 结论

当前项目可以发布为有条件静态预览：

```text
YT-A2 release readiness = preview_ready_with_conditions
```

它已经适合让用户进入并完整体验“盐铁会议复原”的核心路径，也适合展示 A2 材料补强后的退朝后探索能力。

但它还不适合被描述为最终版。下一步应先做 A2 静态发布门报告和人工复核，再决定是否把更多 A2 材料纳入首次主体验。
